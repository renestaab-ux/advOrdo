# Fiktive Testprofile für „Eigene Daten“

Alle Namen, Anschriften, Registernummern und E-Mail-Adressen sind erfunden. Echte Kanzlei- oder Mandatsdaten gehören nie in dieses Verzeichnis.

| Datei | Organisationsform | Passt zu |
|---|---|---|
| `einzelanwalt.json` | Einzelanwalt (Rechtsanwalt Jonas Weidinger, Freiburg) | beliebige Testakte |
| `kanzlei.json` | Kanzlei (Albrecht Tiedemann Rechtsanwälte, drei Berufsträger) | Klägerseite der Testakte Brückner |
| `rechtsabteilung.json` | Rechtsabteilung der Stadtwerke Lindenau GmbH mit zwei Konzerngesellschaften und einer beauftragten Kanzlei | Klägerin der Testakte Hallenbad (Bäderbetriebe Lindenau GmbH) |

So lädst du ein Profil:

1. Unter **Einstellungen → Arbeitsumgebungen** eine neue Umgebung anlegen, z. B. „Test Rechtsabteilung“, und in sie wechseln.
2. **Eigene Daten** öffnen, „Profil importieren“ wählen und die Datei aus diesem Verzeichnis auswählen.
