# Sicherheit

## Sicherheitslücke melden

Bitte melde eine Sicherheitslücke **nicht** als öffentliches Issue, sondern per E-Mail an
**advordo@staab.legal**, Betreff „Sicherheit advOrdo“. Hilfreich sind:

- betroffene Version bzw. Commit und Betriebssystem (Windows, macOS, Linux),
- eine Beschreibung, wie sich die Lücke auslösen lässt,
- was ein Angreifer damit erreichen kann.

Du bekommst in der Regel innerhalb einer Woche eine Antwort. Bis eine Korrektur veröffentlicht ist, bitte
keine Einzelheiten weitergeben.

## Was dazugehört

advOrdo verarbeitet Akten mit vertraulichen Mandatsdaten. Besonders wichtig sind deshalb Wege, auf denen
Dokumentinhalte das Gerät verlassen könnten, ohne dass der Modus „Externer Anbieter“ gewählt ist, auf denen
der Kern einen Netzwerkport öffnet oder auf denen fremder Code in der Oberfläche oder im Kern ausgeführt wird.

Bitte keine echten Mandatsdaten in Meldungen schicken, nur erfundene oder anonymisierte Beispiele.
